## 還缺的資料

| 參數 | 狀況 |
|---|---|
| 土壤有機碳、草酸可萃取鐵、總體密度、含水率 | 詳細土壤圖只有分類（質地、排水、酸鹼性），沒有這些數值；需要土壤調查報告或農試所資料 |
| 土壤 As、Hg、Pb、Cd、Ni、Cr 背景值 | 05 檔查到環保署農地重金屬調查在 scidm 上「此資料集無資料」；查不到公開數值。Cd、Ni、Cr 設 0 |
| 入滲比例 | 嘉南平原的補注量研究還沒找到 |
| 含水層厚度 | 可用地調中心鑽井岩性估算，還沒做 |
| 地下水 Hg、Pb 背景值 | 水利署 161086 的中位數是 0，資料沒有寫偵測極限。環境部區域性地下水監測（WQX_P_02，嘉南平原 94 口井，2014–2025）：Hg 1,809 筆中 1,805 筆低於 0.0003 mg/L，Pb 1,561 筆低於 0.003 mg/L。目前的通用值（Hg 0.005、Pb 0.3 µg/L）比偵測極限低，資料無法判斷對錯，所以維持 ASSUMED；要不要改成 0（和鎘、鎳的做法一致）由你決定 |
| 河川 Hg、Pb 背景值 | 環境部河川資料 2021–2025 有 95%（Hg，偵測極限 0.0003 mg/L）和 75%（Pb，0.003 mg/L）低於偵測極限，所以沒有用中位數 |
| 河川流量 | 找到的三個資料集都沒有個別河川的流量數值 |
| 湖泊參數（底層溶氧、營養狀態、DOC、pH、硫酸鹽、濕地） | 依決定設為下游沒有湖泊（停留時間 0），但這幾個值仍會用在汞的甲基化指標，所以維持 ASSUMED。之後可以考慮在沒有湖泊時改用河口或濕地的判斷 |

注意：

- 河川砷 6.6 µg/L 是總砷（未過濾），當作「溶解態背景值」會偏高。
- 2026-11-15 修正：環境部河川水質 API 會把同一個樣本列兩次（測站登記在兩個鄉鎮，或有兩組座標，數值相同）。`tools/process_chianan_extra.py` 改成每個測站、採樣時間、項目只算一筆後，懸浮泥砂中位數由 19.6 變 19.7 mg/L，河川砷由 6.75 變 6.6 µg/L，樣本數由 751 變 719（金屬）、2,454 變 2,422（懸浮泥砂）。
